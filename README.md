# Transmission Network Reconstruction for HPAI Outbreaks

This repository contains the Python implementation of the transmission model presented in *Modelling assessment of the different paths of between-farm transmission of avian influenza HPAI in Northern Italy in 2021--2022*.

Because the original epidemiological and genetic data are subject to confidentiality restrictions, they are **not included** in this repository. Instead, synthetic datasets reproducing the structure of the original files are provided, allowing the complete workflow to be executed without access to the real data.

The repository reproduces the full analysis pipeline, from network construction and parameter estimation to transmission attribution, genetic validation, and epidemic visualization.

---

# Repository structure

The repository is organized into three main folders:

| Folder | Description |
|------|-------------|
| `Codes/` | Contains the eight Python scripts implementing the complete analysis pipeline, from network construction to epidemic visualization. |
| `Synthetic datasets/` | Contains synthetic input datasets with the same structure, variable names, and formats as the original confidential data, allowing the full workflow to be reproduced without access to the real datasets. |
| `Visualization/` | Contains the epidemic reconstruction videos (MP4) generated by the visualization script for the different transmission scenarios. |

---

# Synthetic datasets

Three synthetic input files are included:

| File | Description |
|------|-------------|
| `fattorie_synthetic.xlsx` | Synthetic farm-level dataset containing farm identifiers, geographic coordinates, company membership, and confirmation dates. |
| `date_culling_synthetic.csv` | Synthetic culling dates for infected farms. |
| `mat_diff_basi_synthetic.csv` | Synthetic pairwise genetic distance matrix between infected farms. |

These datasets preserve the same structure, variable names, and formats as the original data but contain no real epidemiological information.

# Workflow

The complete workflow consists of eight scripts that should be executed sequentially.

---

# 1. Create transmission networks

**Script**

`1_Create_Networks.py`

### Purpose

Constructs the static transmission networks used throughout the analysis.

Two possible transmission mechanisms are represented:

- Same company
- Spatial neighborhood

### Input

- `fattorie.xlsx`

### Parameters

```python
DMAX_VALUES = [1.5, 2.0]
```

where `DMAX_VALUES` defines the maximum neighborhood distance (km).

### Output

- `same_company.xlsx`
- `neighbors_dmax1.5.xlsx`
- `neighbors_dmax2.0.xlsx`

---

# 2. Parameter estimation

**Script**

`2_Codice_Stima.py`

### Purpose

Estimates the transmission model parameters by maximum likelihood while jointly reconstructing latent exposure dates using an iterative EM-like algorithm.

The estimation is repeated using multiple random initializations.

### Input

- `fattorie.xlsx`
- `same_company.xlsx`
- `neighbors_dmaxX.xlsx`

### Main parameters

```python
GAMMA_VALUES = [0, 1/5, 1/10]
DMAX_VALUES = [1.5, 2.0]
SEEDS = range(100,200)
```
Note: if GAMMA_VALUES = 0 we use the constant infectiousness over time (indicator function).

Additional configurable parameters include

- `MAX_ITER`
- `RANGE_DAYS`
- `DAYS_INFECTIOUS`
- `L_CONST`

### Output

For each parameter combination:

- estimated exposure dates
- optimization log
- estimated model parameters

Final summary:

- `risultati_completi.xlsx`

# 4. Dominant transmission mechanisms

**Script**

`4_Dominant_Transmission_Mechanisms.py`

### Purpose

Computes the contribution of the different transmission networks for each infected farm and identifies the dominant transmission mechanism.

For each infected farm, the contributions of the wildlife, same-company, and distance-based transmission components are calculated. Farms belonging to both the same-company and distance-based networks are treated as a separate category, with the contributions from both networks combined.

The dominant transmission mechanism is classified into four categories:

- Wildlife
- Same-company network only
- Distance-based network only
- Both the same-company and distance-based networks

### Input

- `fattorie.xlsx`
- `risultati_completi.xlsx`
- `date_gamma...xlsx`
- `same_company.xlsx`
- `neighbors_dmaxX.xlsx`

### Parameters

```
GAMMAS = [0.100, 0.200]
DMAX_VALUES = [1.5, 2.0]
L_CONST

### Output

For each combination of $\gamma$ and $d_{\max}$, the script provides:

- contribution and probability associated with each transmission mechanism
- dominant transmission mechanism
- probability of the dominant mechanism
- second-highest mechanism probability
- dominance margin
- probability class
- number of potential sources in each transmission network

Main files:

- `dominant_source_classification_gamma..._dmax....xlsx`

# 5. Best infector network classification

**Script**

`5_Best_Infector.py`

### Purpose

Classifies the most likely infector of each infected farm according to its presence in the same-company and distance-based transmission networks.

The most likely infector is obtained from the `best_infector_gamma...xlsx` files generated by the transmission probability analysis. For each infected farm, the inferred infector is classified into mutually exclusive categories according to its network membership:

- Wildlife
- Same-company network only
- Distance-based network only
- Both the same-company and distance-based networks
- Unmatched

A best infector is classified as `Unmatched` when it is not identified as wildlife and is not found in either of the two transmission networks. This category is retained as a control and diagnostic category.

### Input

- `fattorie.xlsx`
- `date_gamma...xlsx`
- `best_infector_gamma...xlsx`
- `same_company.xlsx`
- `neighbors_dmaxX.xlsx`

### Parameters

```
GAMMAS = [0.100, 0.200]
DMAX_VALUES = [1.5, 2.0]

### Output

For each combination of $\gamma$ and $d_{\max}$, the script provides:

- most likely infector
- probability of the most likely infector
- classification according to transmission network
- indication of whether the infector belongs to the same-company network
- indication of whether the infector belongs to the distance-based network
- distance between target farm and infector, when applicable
- summary of the number of farms in each network category
- distribution of the probability of the most likely infector into High ($>0.5$), Medium ($0.1 < P \leq 0.5$), and Low ($\leq0.1$) classes

Main output files:

- `best_infector_network_classification_gamma..._dmax....xlsx`

The output file contains two sheets:

- `Classification`: farm-level classification of the most likely infector
- `Summary`: summary of network categories and probability classes

# 6. Genetic validation

`6_Confronto_Matrice_Genetica.py`

- `best_infector_gamma...xlsx`

### Parameters

- statistical summaries
- boxplots
- hypothesis test results

# 8. Epidemic visualization

**Script**

`8_Visualization.py`

### Purpose

Produces an animated reconstruction of the epidemic and the inferred farm-to-farm transmission network.

For each combination of $\gamma$ and $d_{\max}$, the script uses the transmission probability matrix to display farm-to-farm transmission links and highlights the most likely infector for each infected farm. Links are classified according to the transmission network to which they belong:

- Same-company network
- Distance-based network
- Both networks

When wildlife is identified as the most likely infector of a farm, no farm-to-farm link is displayed for that infection event.

The animation also shows the temporal evolution of the epidemic, including exposed, detected, and culled farms.

### Input

- `fattorie.xlsx`
- `date_culling.csv`
- `date_gamma...xlsx`
- `matrice_gamma...xlsx`
- `best_infector_gamma...xlsx`
- `same_company.xlsx`
- `neighbors_dmaxX.xlsx`

### Parameters

### Output

# Running the pipeline

The scripts should be executed in the following order:

1. `1_Create_Networks.py`
2. `2_Codice_Stima.py`
3. `3_Parametri_Medi_e_Matrice.py`
4. `4_Dominant_Transmission_Mechanisms.py`
5. `5_Best_Infector.py`
6. `6_Confronto_Matrice_Genetica.py`
7. `7_Gap_Best_Infector.py`
8. `8_Visualization.py`

# Configurable model parameters

The analyses can be repeated under different epidemiological assumptions by modifying:

- `GAMMA_VALUES` (infectiousness decay parameter)
- `DMAX_VALUES` (maximum neighborhood distance)
- `SEEDS` (random initializations)
- `L_CONST`
- `RANGE_DAYS`
- `DAYS_INFECTIOUS`

Different combinations automatically generate independent sets of output files.
